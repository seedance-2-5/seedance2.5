## English

### About Seedance2.5

Seedance2.5 is an independent AI video generation platform built for creators, marketers, production teams, developers, and SaaS builders. It brings prompt-based creation, reference-led direction, practical generation tools, and API access into one streamlined workflow.

The platform is designed to help people move from an idea to a polished moving image with less production friction. A creator can explore a visual concept in the browser, a marketing team can produce and compare campaign variations, and a developer can bring the same generation workflow into an application or internal system through the API.

Our goal is simple: make cinematic AI video creation easier to try, easier to direct, and easier to scale.

### What You Can Create

Seedance2.5 supports a wide range of creative and production workflows:

- **Cinematic short videos** — Turn a written idea or creative brief into a polished clip with intentional framing, lighting, movement, pacing, and atmosphere.
- **Reference-guided videos** — Use images and other supported reference materials to guide the subject, visual style, composition, motion, or overall creative direction.
- **Advertising creatives** — Produce product reveals, campaign hooks, paid-social variations, landing-page videos, and promotional concepts.
- **Creator content** — Build vertical or horizontal content for TikTok, Instagram Reels, YouTube Shorts, and other publishing channels.
- **Product and brand visuals** — Keep a recognizable product or visual identity at the center of launch videos, ecommerce assets, and brand storytelling.
- **Story concepts and previsualization** — Explore scenes, camera ideas, transitions, pacing, and narrative direction before committing to full production.
- **Repeatable content workflows** — Generate variations for ongoing campaigns, content calendars, product catalogs, and team review processes.
- **Embedded AI experiences** — Add video and supported image-generation workflows to SaaS products, internal tools, or automated production systems through the API.

### Core Platform Capabilities

#### Prompt-to-Video Creation

Describe the subject, action, setting, shot design, camera movement, lighting, mood, pacing, and sound direction in natural language. Seedance2.5 turns that creative intent into a generation-ready workflow without requiring a traditional video-production setup.

#### Reference-Led Creative Control

Prompts establish the intent; references make the direction more concrete. Depending on the selected model and workflow, creators can use supported images, videos, or audio references to communicate identity, movement, composition, atmosphere, timing, and visual language.

#### Creator-Friendly Web Studio

The browser-based generation experience keeps creation practical: select a model, provide a prompt and supported references, configure the available output settings, start a task, and review the result. Current model options, duration, resolution, aspect ratio, format, and reference limits are shown directly in the generator.

#### Fast Validation and Iteration

Free usage opportunities help new users test prompts and creative directions before moving to larger paid workloads. Credit-based generation makes it easier to match usage with the model, quality, duration, resolution, and production volume required by each project.

#### Task and Asset Management

Users can follow generation progress, review recent tasks, access generated assets, and manage account credits from the dashboard. This makes the platform useful for both one-off experiments and ongoing creative production.

#### Developer API

Seedance2.5 provides API workflows for teams that need generation inside their own products or systems. Developers can authenticate with an API key, create generation tasks, poll task status, read generation history, and check account or credit information.

### A Simple Creative Workflow

1. **Define the idea** — Write a prompt that explains the subject, action, setting, camera, lighting, pacing, mood, and desired outcome.
2. **Add references** — Upload supported reference assets when you need stronger control over identity, style, motion, composition, or atmosphere.
3. **Configure the output** — Choose from the options exposed by the selected model, such as duration, resolution, aspect ratio, format, visibility, or quality.
4. **Generate and review** — Start the task, monitor its status, and inspect the generated result.
5. **Refine or scale** — Adjust the prompt and references for another variation, or move the workflow into an application through the API.

### Developer Workflow

The API follows a task-based generation flow:

1. Create an account and generate an API key from the dashboard.
2. Send the key as `Authorization: Bearer YOUR_API_KEY`.
3. Start a generation task with the documented model ID and payload fields.
4. Poll the task endpoint when asynchronous status tracking is supported.
5. Read recent generation records and generated-asset history.
6. Check the account profile, remaining credits, and membership status as needed.

Each model can expose different payload fields and generation options. Always use the current model schema and examples in the [API documentation](https://seedance25free.com/docs/api) rather than assuming that every model accepts the same input.

## 简体中文

### 关于 Seedance2.5

Seedance2.5 是一个独立的 AI 视频生成平台，面向内容创作者、营销团队、视觉制作团队、开发者和 SaaS 产品团队，将提示词创作、参考素材控制、实用的在线生成工具与 API 接入整合到一套清晰的工作流中。

平台致力于降低从创意到成片的制作门槛：创作者可以直接在浏览器中验证视觉想法，营销团队可以快速生成并比较多组营销素材，开发者也可以通过 API 将同样的生成能力接入自己的应用、内部工具或自动化内容系统。

我们的目标很简单：让电影感 AI 视频创作更容易体验、更容易控制，也更容易规模化。

### 可以创作什么

Seedance2.5 可用于多种创意与生产场景：

- **电影感短视频** — 将文字创意或制作需求转化为具有明确构图、灯光、运动、节奏和氛围的精致短片。
- **参考素材驱动的视频** — 使用图片及当前工作流支持的其他参考素材，引导主体、视觉风格、画面构成、运动或整体创意方向。
- **广告与营销素材** — 制作产品展示、广告开场、付费社交媒体变体、落地页视频和推广概念片。
- **创作者内容** — 为 TikTok、Instagram Reels、YouTube Shorts 等内容渠道生成横版或竖版视频。
- **产品与品牌视觉** — 围绕清晰的产品或视觉识别，制作新品发布、电商展示和品牌叙事内容。
- **故事概念与预演** — 在正式制作前探索场景、运镜、转场、节奏和叙事方向。
- **可重复的内容工作流** — 为长期营销活动、内容日历、产品目录和团队审核流程持续生成素材变体。
- **嵌入式 AI 能力** — 通过 API 将视频及支持的图像生成工作流接入 SaaS 产品、内部工具或自动化生产系统。

### 核心平台能力

#### 提示词生成视频

使用自然语言描述主体、动作、场景、镜头设计、运镜、灯光、情绪、节奏和声音方向。Seedance2.5 会将这些创作意图整理为可执行的生成工作流，无需传统视频制作环境也能快速开始。

#### 参考素材驱动的创意控制

提示词负责表达意图，参考素材让方向更加具体。根据所选模型与工作流，创作者可以使用当前支持的图片、视频或音频参考，传达主体身份、动作、构图、氛围、节奏和视觉语言。

#### 对创作者友好的在线工作室

浏览器端的生成体验保持了清晰、实用的操作流程：选择模型，输入提示词和支持的参考素材，配置可用的输出选项，创建生成任务，然后查看结果。当前模型支持的时长、分辨率、宽高比、格式和参考素材限制，以生成器页面实时展示为准。

#### 快速验证与迭代

免费体验机会可以帮助新用户先验证提示词和创意方向，再决定是否扩大付费生成规模。积分制生成则让团队可以根据不同项目所需的模型、质量、时长、分辨率和产量灵活安排成本。

#### 任务与素材管理

用户可以在控制台中跟踪生成进度、查看近期任务、访问已生成素材并管理账户积分。因此，Seedance2.5 既适合一次性的创意实验，也适合持续性的内容生产。

#### 开发者 API

对于需要在自有产品或系统中使用生成能力的团队，Seedance2.5 提供完整的 API 工作流。开发者可以使用 API Key 完成鉴权、创建生成任务、轮询任务状态、读取生成历史，并查询账户或积分信息。

### 简单的创作流程

1. **定义创意** — 用提示词说明主体、动作、场景、镜头、灯光、节奏、情绪和预期效果。
2. **添加参考素材** — 需要更准确地控制主体、风格、动作、构图或氛围时，上传当前模型支持的参考素材。
3. **配置输出** — 根据所选模型提供的选项设置时长、分辨率、宽高比、格式、可见性或质量等参数。
4. **生成并查看** — 创建任务、跟踪状态并检查生成结果。
5. **继续优化或规模化** — 调整提示词与参考素材生成新版本，或者通过 API 将工作流接入自己的应用。

### 开发者接入流程

API 采用任务式生成流程：

1. 创建账户，并在控制台生成 API Key。
2. 通过 `Authorization: Bearer YOUR_API_KEY` 发送鉴权信息。
3. 使用文档中提供的模型 ID 和请求参数创建生成任务。
4. 对支持异步状态查询的任务轮询状态接口。
5. 读取近期生成记录与已生成素材历史。
6. 按需查询账户资料、剩余积分和会员状态。

不同模型可能提供不同的请求字段和生成选项。接入时请始终以最新的[API 文档](https://seedance25free.com/docs/api)中的模型 Schema 和示例为准，不要假设所有模型都接受相同参数。
